Painel Soneda
Demo estatica com dados ficticios para portfolio. Sem banco, sem servidor e sem dados confidenciais.

Visao comercial Soneda

Automacao de uma rotina antes feita em planilha dinamica: consolidacao de sell out, estoque e recortes por loja, categoria, familia e produto.
